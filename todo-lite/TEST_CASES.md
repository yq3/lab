## 自测发现并修复的问题

1. **备注关闭丢失**（TC-14）：textarea 卸载不触发 onBlur，关闭面板时备注不保存 → 改为输入 400ms 防抖自动保存
2. **Hook 顺序崩溃**：`useRef` 误放在条件 return 之后，打开详情面板时 React 崩溃白屏 → 移到组件顶部
3. **点 label 误关面板**（TC-32）：点"备注/优先级"等 label 触发空白关闭逻辑 → label 加入排除列表
4. **恢复任务不恢复子任务**（TC-27）：删除任务级联软删子任务，但恢复只恢复父任务 → restoreTask 同步恢复子任务
5. （M6 已修复）托盘 Down/Up 双击翻转、通知轮询 30s 窗口漏发、productName 错名
