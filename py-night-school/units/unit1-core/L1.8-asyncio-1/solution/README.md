# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1 的骨架就是所有 asyncio 程序的骨架：`asyncio.run(main())` 打 border，`main` 里逐个 `await`；
  顺序 await 的总耗时 = 各段相加——这正是下一课 gather 要消灭的东西。
- ex2 只改一行（外加删掉失效 import）。值得回味的不是写法，是断言方式：
  验收老师用「三个 start 挤在最前面」证明并发真的发生了——时间戳会抖，事件顺序不会。
- ex3 的关键纪律：协程对象是一次性的。三个归宿各造各的对象，
  造了不用要 `close()`，否则解释器在回收时报 never awaited。
