# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1：两层结构（timing 收函数 / wrapper 做包装）+ `@wraps(func)` 的位置——它永远贴在「真正包住原函数」的那层 def 上一行。
- ex2：三层结构从外到内分别是「参数 -> 函数 -> 包装」；耗尽时用**裸 raise**（不带异常对象），它重抛的是当前 except 捕获的那一个，且保住原始 traceback——L1.7 会正式讲。
- ex3：注册型装饰器**原样返回 func**，这与增强型（返回 wrapper）形成对照——装饰器能干的不止「包一层」。
