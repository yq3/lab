# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- **ex1** 的考点不在三条规则（L0.1 就写过），而在 `preapprove` 只消费 `RULES` 列表本身——
  注入测试（往链头插一条规则行为立刻变）验证的正是「规则是数据」这个架构事实，
  硬编码 if 链过不了它。
- **ex2** 两个细节：`return greet` 不带括号（返回函数本身）；`nonlocal state` 是「写外层」的
  门票。两个计数器不串台，是闭包环境对全局变量的完胜演示。
- **ex3** 的 keyword-only 由签名里的 `*` 把关，行为测试（位置传参 TypeError）与
  签名形态测试（`inspect.Parameter.KEYWORD_ONLY`）双保险；`**options` 透传一行搞定，
  多余的键让 TypeError 在摊开处自然炸出——校验交给签名，不自己造。
