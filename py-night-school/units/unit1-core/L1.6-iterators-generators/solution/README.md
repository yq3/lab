# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1：`yield items[i : i + size]` + `i += size`——切片天然处理「最后一页不满」；`size <= 0` 的校验写在生成器体内，测试用 `list()` 消费时触发（生成器函数体到第一次 `next` 才执行，这是 §2.3 讲过的语义）。
- ex2：三段全是生成器函数，组合处**不物化**（中途 `list()` 会让短路测试的计数变成 5——惰性必须保留到最后一刻）。
- ex3：物化修复一行 `list(read_amounts(LINES))`。「每次重建生成器」同样是正解，但它要求改函数体，为守住单变量约束本练习只收物化版。
