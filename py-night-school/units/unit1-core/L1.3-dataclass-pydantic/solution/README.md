# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- **ex1** 的唯一真考点是 `tags: list[str] = field(default_factory=list)`——可变默认值的纪律写法；
  其余字段声明是「翻译」：`self.x = x` → `x: 类型`。
- **ex2** 展示三类约束参数（`pattern` / `gt`+`le` / `min_length`）与一张「覆盖三字段 + 上下边界」的
  非法样本表——meta-test 判定的正是覆盖是否达标；注意 `kind` 与真实违规字段必须一致，诚实是约束的一部分。
- **ex3** 的 `from_lines` 只做解析与转发，零个 `if` 做业务判断——「校验发生在构造那一刻」的全部含义：
  把数据推向模型，让 ValidationError 替你说话。`model_dump()` 的逐键断言是嵌套结构的最终判据。
