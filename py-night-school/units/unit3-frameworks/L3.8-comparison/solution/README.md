# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1 的认知支点是「五课平等对版」：基准取众数指纹而不是钦定某一课——谁偏离多数派谁
  就是 drift；并列取字典序最小是确定性纪律（同一组输入永远同一列，对照 langgraph
  归并顺序按 task path 排序的同款坚持）。两个 pass（先收集指纹、再组装列）比一个
  pass 里边算边定基准好读。
- ex2 的六格映射每格都有一个「压倒性关键词」：断电恢复（L3.3）／零锁定（milestone）／
  三件套（L3.5）／调试器+eval（L3.6）／画布（L3.7）／最薄原语（L3.1）。理由写关键词
  + 课次即可，长篇大论反而说明你没找到那个关键词。
- ex3 是覆盖型 meta-test：七行 TODO 的解法不唯一，但断言强制覆盖——deepagents 必须
  出现、「框架判据」至少两行、维度白名单。写你真有体感的行（比如你亲手翻过车的那个
  trace 外发），自查表才有自查的价值。
