# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1 的装配顺序就是讲义 demo.build_graph 的顺序：先挂节点再连边，START 出发、END 收口，
  条件边只挂在 reviewer 之后——「回边成环 + 条件边」两行就是 L2.3 那个 while 的全部图形态。
- ex2 的 events 声明与登记缺一不可：只加字段不登记，流水是空的；只登记不加 Annotated，
  reducer 退化为覆盖，流水只剩最后一条（测试的精确序列断言两头都堵死了）。
- ex3 的关键一行是 `add_node("review", build_review_subgraph(model))`——图即节点；
  deny 短路之所以 0 请求，是因为条件边把非法单号路由到了不碰模型的节点：
  「省钱的分支」在图里就是一条不经过模型节点的路径。
