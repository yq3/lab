# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1 的循环体与讲义 `ReActAgent.run` 同构：先 append 再分支，让「原样入史」成为
  不可跳过的第一步——先分支后 append 的写法容易在 return 路径上漏掉最终 assistant 消息。
- ex2 的两个出口隔着 for 的边界：循环内 return（软终止），循环外 raise（硬终止）。
  执念模型走不到 return 不是 bug 是考点——软终止是概率的，硬终止是你的。
- ex3 的内层 while 必须在每次 pop(1) 之后立刻跑——孤儿 tool 检查是「每裁一条查一次」，
  不是「裁完统一查」；后者会在连续两轮 tool 消息的边界上漏判。
