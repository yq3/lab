# 参考答案

先完成练习再进来。对照要点：不追求与你的写法一致，追求**通过验收 + 读得舒服**。

- ex1 的三查共用一个形状：先问「输入可信吗」（fail-closed 分支在前），再问「超限了吗」。
  第 6 查的比较符是 `>=`——到期那一刻就算过期（边界宁严勿松，对版产品的 expiry 检查同款）。
- ex2 的关键是 verify_chain 里「重算哈希时的 payload 要把三个保留键剔掉」——忘了剔，好链
  也会被自己验坏；以及 append 先 verify 再写：断链拒写比对得多更重要（合规账本宁停不脏）。
- ex3 的顺序一条都不能换：标记落盘失败返回 REFUSED 时 broker 一次都没被碰；
  broker.pay 的异常直接上抛、标记不动——恢复的唯一入口是 reconcile，而它只取证、绝不重发。
