## 任务原文

（DESIGN §6.3 + §7.2/§7.3 + §10 M6；验收标准对应 TEST-CASES TC-WIN-01~07 + TC-APP-04~12 相关项）

**M6 范围（8 项）：**

1. **拖拽**：pet 窗口非穿透态下（运行时默认）webview 收 mousedown → Tauri `window.startDrag()` 实现拖拽；松开停止。不做"穿透时临时关穿透再拖"路径（DESIGN §6.3 明示该设想不成立，v1 不做）。
2. **跨显示器拖拽**：`availableMonitors()` 计算屏幕边界，跨屏拖拽实时更新窗口位置，不被边缘卡住（TC-APP-11）。
3. **位置记忆升级**：宠物位置 + 所在显示器 id 写入 `pulsepet.db` `app_state` 表（坐标单位=物理像素 `PhysicalPosition`/`outer_position`）；启动时还原上次显示器 + 坐标；若显示器已不存在则回退主显示器，不崩溃、不显示在屏幕外（TC-APP-09/10）。
4. **右键菜单**：非穿透态右键宠物弹出 `PetMenu.tsx`，含"设置/切换交互模式"等入口（TC-WIN-03）。
5. **穿透可切换**：`setIgnoreCursorEvents` 动态切换；穿透开=纯展示（鼠标穿透+不可拖拽、右键不可达），穿透关=可拖拽/右键；切换通道=全局热键+托盘菜单双通道，状态同步（TC-WIN-02/04/05）；默认仍非穿透。
6. **全局热键**（tauri-plugin-global-shortcut）：`⌘+Shift+P`（Win `Ctrl+Shift+P`）切换 panel 可见（与托盘唤起状态同步）；`⌘+Shift+Alt+P`（Win `Ctrl+Shift+Alt+P`）切换宠物穿透；`⌘+Shift+Alt+F`（Win `Ctrl+Shift+Alt+F`）调试烟花（手动放一束；v1 release 构建中移除）。与 opencode 默认热键（`Ctrl+O` 等）不冲突（TC-APP-06/07/08、TC-WIN-07）。
7. **托盘菜单补全**：右键菜单加"切换交互模式（穿透开/关）"项（CheckMenuItem 态同步），完整五项：显示/隐藏宠物、切换交互模式、打开控制面板、暂停所有提醒、退出（TC-APP-04/05）。
8. **M5 遗留 P2 顺带清偿**（来源 task-pulsepet-m5 committer R1）：① gen-assets.mjs blitCat blink 分支死代码（idle 常驻造型后无调用方，补"保留备用"注释）；② genCatAtlas pal 遗留未用键 W2 删除；③ assets/blinking-kitty/pet.json description"idle 6 帧不规则眨眼"措辞与常驻单眼缝视觉不一致（重跑 gen-assets 即修）。

**范围外（继续移交，不在本任务处理）：** M5 P2 ⑤ list_pets_in 慢（M7/M8）、⑥ decode_sheet 解压炸弹防护（M7/M8）、⑦ resolve_requested 不可达分支（可不动）；M4 P2 ① cover_monitor 竞态（M8 多屏实机）、②③ todo 相关（M7）、④ dismissed_via NULL（M7/M8 前可选）、⑥ .catch 静默吞（可留待后续）、⑦ watchdog 截断（概率极低）；限流豁免 /health（心跳引入时）；install.ps1 BOM / classifyEvent permission.asked（M8）；Windows 实机验证（M8）；多显示器烟花绽放点实机（M8）；多显示器跨屏烟花（M6 后评估，不在 M6）；M5 观察项 ①②③（可不动/环境容差/设计结果）。
