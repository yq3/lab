# 个税年度汇算操作指引

## 什么情况需要年度汇算

- 综合所得（工资薪金 + 劳务报酬 + 稿酬 + 特许权使用费）年度合并计税，与已预缴税款存在差异时。
- 典型应退税：劳务报酬/稿酬占比高（预扣率高于年度适用税率）、中途换工作扣除重复或不足。
- 典型应补税：多处收入合并后级距跳档、年终奖计税方式选择变化。

## 办理流程（对应本系统的 agent 分工）

1. 路由到计税 agent（delegate_to_tax_calc）：折算收入额 → 汇总扣除 → 分级计税 → 得出应补(退)税额。
2. 向用户确认计税结论（金额、适用级距、扣除明细）。
3. 用户要求申报时 → 人工审批 → 委派申报 agent（delegate_to_tax_filing）。
4. 回报告执号；应补税提醒用户在 6 月 30 日前缴清，应退税等待国库退还（1-2 周）。

## 注意事项

- 扣除材料不齐的项执行 fail-closed：先不计入，提示用户补齐后重新汇算（可退税的情形补齐材料通常更划算）。
- 金额一律整数元；结论以计税 agent 的结构化输出为准。
