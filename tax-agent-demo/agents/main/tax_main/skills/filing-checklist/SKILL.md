# 申报提交前核对清单

## 提交前逐项确认

1. 计税结论已存档（save_calc_result）且用户已知悉应补(退)金额。
2. 纳税人档案信息一致：姓名、编号、年度。
3. 专项附加扣除佐证材料全部齐全（verify：计税 agent 的 warnings / 申报 agent 的 validate）。
4. 用户明确说过"提交申报"（不要把"帮我算算"理解为要提交）。

## 缺材料时的处理路径

- 申报 agent 会把任务置为"等待补充信息"（A2A input-required），并给出缺失清单。
- 向用户转达缺失项（如：继续教育的执业资格证书复印件），收集齐后**重新完整委派**申报任务
  （远端 agent 无状态首触，需要带上全部计税数据 + "材料已补齐"的说明）。

## 提交红线

- 人工审批必须走（系统强制，不要绕过）；用户否决即停，记录顾虑。
- 幂等键固定用 "纳税人编号-年度" 格式：网络重试不会造成重复申报。
- 提交成功后回报告执号（RCP- 开头），并提示受理记录存进程内存（demo 设定）。
